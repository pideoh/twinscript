# Display text

- No user-visible text is written inline. Use `t('key', params)` in JavaScript and `data-i18n`, `data-i18n-title`, `data-i18n-aria-label` or `data-i18n-placeholder` in `index.html`.
- Modules without UI (`audio.js`, `transcriber.js`, `translator.js`) throw `MessageError(key, params)`; `app.js` translates it.
- Add every new key to **all** files in `src/ui/locales/`, with the same `{placeholders}`. `en.js` is the reference and the fallback. `test/unit/rules/i18n.test.js` fails on a missing key or placeholder.
- English copy: sentence case, concise, no exclamation marks. Do not machine-translate product names or setting paths of the operating system without checking the real label.
- Names of the spoken languages come from `Intl.DisplayNames`; do not add them to the catalogs.
- The translation prompt in `translator.js`, the preset prompts in `summary-templates.js` and the demo speech in `mock.js` are not translated. The names and descriptions of the preset templates are.
