# Gemini の API キーを取得する

Twinscript は、あなた自身のキーで Google の Gemini API を使います。取得に必要なのは Google アカウントだけで、数分で終わります。

1. [Google AI Studio](https://aistudio.google.com/apikey) を開き、Google アカウントでログインします。
2. API キーを作成します。キーを置く Google Cloud のプロジェクトを尋ねられたら、新しく作成させます。
3. キーをコピーします。
4. Twinscript の設定（右上の歯車のボタン）を開き、「Gemini APIキー」に貼り付けて保存します。
5. 2つの言語を選び、「翻訳開始」を押します。

キーは OS の機能で暗号化され、お使いの PC の中だけに保存されます。[プライバシー](../README.ja.md#プライバシー)を見てください。

## 無料と有料

作成したばかりのキーは無料枠で動きます。無料枠にはレート制限があります。また、無料枠で送信した内容は Google の製品改善に
使われることがあるので、社外秘の会議では有料のキーを使ってください。有料にするには、AI Studio でキーのプロジェクトを
Google Cloud の請求先アカウントに紐づけます。料金は[料金](../README.ja.md#料金)にあります。

## うまくいかないとき

| 表示 | 対処 |
| --- | --- |
| 開始を押すと、キーの入力を求められる | キーがまだ保存されていません。設定で入力します。 |
| 接続に失敗したという表示に、API キーや権限のことが書かれている | キーの入力ミスか、キーが削除されています。AI Studio からコピーし直します。 |
| レート制限の表示 | 無料枠の上限に達しています。途中の文の翻訳を1分間止め、確定した文の翻訳は続けます。 |
